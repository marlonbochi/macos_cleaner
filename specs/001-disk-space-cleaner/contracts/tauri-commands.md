# Contract: Tauri IPC commands

The interface between the Vue frontend and the Rust core. Every type is generated by `ts-rs` into
`src/types/generated/` (the CI fails if the generated files drift). Errors are returned as a
serialised `AppError`:

```ts
type AppError = { code: ErrorCode; message: string };
type ErrorCode =
  | "NOT_FOUND" | "INVALID_INPUT" | "PERMISSION_DENIED" | "SCAN_IN_PROGRESS"
  | "PROTECTED_PATH" | "AI_UNAVAILABLE" | "CLOUD_UNSUPPORTED" | "STORAGE" | "INTERNAL";
```

Shared pagination:

```ts
type PageDto<T> = { items: T[]; total: number; offset: number; limit: number };
```

## Scanning and catalogue (US1) — implemented

| Command | Args | Returns | Notes |
|---|---|---|---|
| `get_scan_defaults` | — | `ScanDefaultsDto` | home folder, default roots, default threshold |
| `start_scan` | `{ roots: string[]; minFileSize?: number; onProgress: Channel<ScanEvent> }` | `ScanSummaryDto` (status `Running`) | `SCAN_IN_PROGRESS` if one is running; roots must be existing folders |
| `cancel_scan` | `{ scanId: number }` | `void` | idempotent; stops within 2 s |
| `get_latest_scan` | — | `ScanSummaryDto \| null` | latest `Completed`/`Cancelled` |
| `list_files` | `{ scanId; offset; limit (≤500); filter?: FileFilterDto; sort?: "sizeDesc" \| "sizeAsc" \| "modifiedAsc" }` | `PageDto<FileEntryDto>` | ordering done in the database |
| `list_folder_children` | `{ scanId; path; offset; limit }` | `PageDto<FileEntryDto>` | folder drill-down |
| `reveal_in_finder` | `{ path }` | `void` | FR-011 |
| `get_permissions_status` | — | `PermissionsStatusDto` | FR-010; includes which app needs Full Disk Access |
| `open_full_disk_access_settings` | — | `void` | opens System Settings |

```ts
type FileFilterDto = {
  minSize: number | null; extensions: string[]; pathPrefix: string | null; kinds: FileKindDto[];
};

type ScanEvent =
  | { type: "started"; summary: ScanSummaryDto }
  | { type: "progress"; filesSeen: number; bytesSeen: number; inaccessibleCount: number; currentPath: string } // ≤ 1 per 100 ms
  | { type: "inaccessible"; path: string }   // first 200 only; the total is in progress events
  | { type: "finished"; summary: ScanSummaryDto }
  | { type: "error"; message: string };

type ScanSummaryDto = {
  id: number; roots: string[]; status: "Running" | "Completed" | "Cancelled" | "Failed";
  minFileSize: number; startedAt: number; finishedAt: number | null; filesSeen: number;
  bytesSeen: number; inaccessibleCount: number; error: string | null; incomplete: boolean;
};

type FileEntryDto = {
  id: number; path: string; name: string; kind: "File" | "Directory" | "Package";
  sizeOnDisk: number; apparentSize: number; fileCount: number;
  modifiedAt: number | null; accessedAt: number | null; isProtected: boolean;
};

type PermissionsStatusDto = {
  fullDiskAccess: boolean;
  target: { name: string; appPath: string | null; isDevHost: boolean } | null;
};
```

## Risk analysis and AI settings (US2) — implemented

| Command | Args | Returns | Notes |
|---|---|---|---|
| `analyze_file` | `{ fileId; force: boolean }` | `AnalysisDto` | cache unless `force`; rules fallback |
| `analyze_files` | `{ fileIds: number[] (≤200); force: boolean }` | `AnalysisDto[]` | batches of up to 20 items per AI request |
| `get_analyses` | `{ fileIds: number[] }` | `AnalysisDto[]` | stored analyses still matching each item (badges) |
| `get_ai_settings` | — | `AiSettingsDto` | never returns the key |
| `save_ai_settings` | `{ input: SaveAiSettingsInput }` | `AiSettingsDto` | key goes to the Keychain; model and URL validated |
| `list_ai_models` | `{ provider; baseUrl: string \| null; apiKey: string \| null }` | `AiModelDto[]` | typed key may be tried before saving; never stored by this call |
| `test_ai_connection` | — | `ConnectionTestDto` | saves nothing; sends a tiny structured request |

```ts
type RiskLevelDto = "Safe" | "Unknown" | "Caution" | "Dangerous";
type RecommendationDto =
  | "delete-safely" | "use-app-or-command" | "move-to-cloud-or-external" | "keep" | "review-manually";
type AnalysisDto = {
  fileId: number; level: RiskLevelDto; category: string; summary: string; explanation: string;
  recommendation: RecommendationDto; steps: string[];
  commands: { command: string; description: string }[];   // displayed only, never executed
  source: { kind: "protectedRule" } | { kind: "heuristic" } | { kind: "ai"; provider: string; model: string };
  createdAt: number;
  aiError: string | null;   // AI configured but failed; local rules answered
};

type AiProviderIdDto = "anthropic" | "openai" | "gemini" | "ollama";
type AiSettingsDto = {
  provider: AiProviderIdDto | null; model: string | null; baseUrl: string | null;
  providers: {
    id: AiProviderIdDto; label: string; defaultModel: string; defaultBaseUrl: string;
    needsApiKey: boolean; hasApiKey: boolean;
  }[];
};
type SaveAiSettingsInput = {
  provider: AiProviderIdDto | null; model: string | null; baseUrl: string | null;
  apiKey: string | null;      // null/empty keeps the stored key
  clearApiKey: boolean;
};
type AiModelDto = { id: string; label: string };
type ConnectionTestDto = { provider: string; model: string };
```

  token: string; // binds the execution to exactly this review (expires after 10 min)

};
